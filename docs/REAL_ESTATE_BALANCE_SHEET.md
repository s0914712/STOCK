# 房地產股票｜資產負債表解讀

這個分頁只處理上市 **建材營造** 公司，目標不是產生買進訊號，而是把營建股最重要的資產負債表資訊先整理成可比較、可追蹤的風險視角。

## 第一層：官方摘要表可以可靠解讀的欄位

1. **流動比率** = 流動資產 / 流動負債
   - 看短期資金結構與償債緩衝。
   - 但營建業流動資產通常包含房地、土地與在建存貨，所以不能把高流動比率直接解讀成「現金很多」。

2. **負債比** = 總負債 / 總資產
   - 看整體槓桿。
   - 同業比較比固定門檻更重要；建商取得土地與興建工程本來就會使用負債。

3. **權益比** = 總權益 / 總資產
   - 看股東資本安全墊。
   - 與負債比互為補充，不代表資產帳面價值等於市價。

4. **營運資金 / 資產** = (流動資產 - 流動負債) / 總資產
   - 看短期資金結構是否緊張。
   - 若為負值，需要再拆解借款、應付款、合約負債與交屋時程。

5. **保留盈餘 / 權益**
   - 看淨值有多少來自歷年累積盈餘，而非股本或資本公積。

6. **每股參考淨值與 P/B**
   - P/B < 1 代表市價低於帳面淨值，但不能直接等同土地折價，因為土地可能按歷史成本、重估方式與個別案場狀況不同。

## 第二層：營建股真正需要從 MOPS / XBRL 深挖的科目

- 現金及約當現金
- 房地 / 土地存貨
- 在建工程
- 合約負債 / 預收款
- 短期借款
- 長期借款
- 一年內到期長期負債
- 利息費用 / 資本化利息

這些科目才能進一步計算：

- **淨負債** = 有息負債 - 現金
- **房地存貨 / 資產**：判斷資產集中度與去化壓力
- **合約負債 / 房地存貨**：近似預售覆蓋程度
- **短期有息負債 / 現金**：再融資壓力
- **存貨成長 vs 營收/交屋**：判斷庫存堆積或新案擴張

## Safety Score 的定位

目前頁面上的 Balance Sheet Safety Score 是同業橫斷面排序：

- 30% 流動比率 percentile
- 25% 反向負債比 percentile
- 20% 權益比 percentile
- 15% 營運資金 / 資產 percentile
- 10% 保留盈餘 / 權益 percentile

它只代表 **摘要資產負債表結構的相對緩衝**，不是買進評等，也不是完整信用評等。由於官方摘要表沒有把房地存貨與有息負債拆開，這個分數不應單獨用來決定投資。
