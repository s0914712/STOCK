# 台灣恐懼與貪婪指數（實驗版 v0.1）

這是一個可重現、可稽核的市場情緒指標，不是任何第三方網站指數的複製品。每日程序只讀取 TWSE、TAIFEX 與金管會公開資料，保存各訊號原始值、資料日期、來源、計算方式與錯誤狀態。

## 計分原則

每項訊號先以固定錨點線性轉成 0–100 分，再裁切至該區間；0 代表偏恐懼，100 代表偏貪婪。九項等權平均，只有 9/9 都取得時才發布綜合分數。固定錨點有版本號，可避免新增資料後回頭改寫舊分數。

分類區間：0–24 極度恐懼、25–44 恐懼、45–55 中性、56–75 貪婪、76–100 極度貪婪。

| 訊號 | 原始值定義 | 恐懼錨點 | 貪婪錨點 | 頻率／來源 |
|---|---|---:|---:|---|
| 選擇權波動率 | TAIFEX VIX 最後 1 分鐘平均 | 40 | 10 | 每日／TAIFEX |
| 賣權／買權比率 | TXO 賣權未平倉 ÷ 買權未平倉 | 130% | 70% | 每日／TAIFEX |
| 美元／新台幣匯率 | USD/TWD 20 個觀察值變動率 | +3% | -3% | 每日／TAIFEX |
| 融資維持率代理值 | Σ（個股融資餘額交易單位 × 收盤價）÷ 全市場融資金額 | 130% | 220% | 每日／TWSE，衍生值 |
| 境外機構期貨持倉 | 外資台指期貨未平倉淨口數 | -60,000 | +30,000 | 每日／TAIFEX |
| 市場廣度 | 上漲普通股 ÷（上漲＋下跌普通股） | 20% | 80% | 每日／TWSE OpenAPI |
| 融券／融資比率 | 全市場融券餘額交易單位 ÷ 融資餘額交易單位 | 8% | 1% | 每日／TWSE |
| 指數動量 | 加權指數 20 個交易日報酬率 | -15% | +15% | 每日／TWSE |
| 有交易帳戶 | 集中市場交易人數月增率 | -20% | +20% | 每月／金管會統計 |

> 「融資維持率」是由公開日資料推導的市場整體代理值，不等同券商對個別帳戶計算的法定追繳維持率。月頻交易人數採每日運算當時最新已公布月份，快照會另外標示 `asOf` 與 `publishedAt`。

## 執行與輸出

```bash
npm run sentiment:daily
```

程序會以交易所最新交易日為主日期，平行取得其餘來源，並以原子寫入方式更新：

- `data/dashboard/fear_greed_latest.json`：完整最新快照。
- `data/dashboard/fear_greed_history.jsonl`：依交易日 upsert 的歷史帳本，重跑同一天不會產生重複列。

GitHub Actions 在台北時間每週一至週五 18:30 執行。介面透過 `GET /api/fear-greed` 取得最新快照；`?history=1&limit=30` 可選擇取得最多 365 筆精簡歷史資料。

## 失敗與資料品質

- 任一來源失敗或值無法解析，報告狀態為 `partial`，`score` 與 `label` 皆為 `null`。
- HTTP 請求含逾時與指數退避重試；來源錯誤會縮短後寫入對應訊號，不會冒充為 0 分。
- 每日帳本依 `tradingDate` 更新，可在週末或休市日安全重跑。
- v0.1 錨點屬透明的啟發式基準，尚未宣稱具預測力。後續應以足夠長的未來資料做版本化回測，而不是用同一批資料反覆調參。

本指數只描述市場情緒，不構成投資建議。
