先記住三件事

順序不能打亂昨天、今天、明天不是可互換的樣本。
價格不等於報酬短期變化模型常分析報酬、差分或波動；價格水準與共整合問題則可能保留水準資料。
未來資料才算考試歷史擬合漂亮只是練習；Forward OOS 才是上線後的成績。

01 · FOUNDATION

什麼是時間序列？

時間序列是一串按照時間排列的觀測值，例如台積電每日收盤價、加權指數每五秒成交量，或公司每月營收。它和一般表格資料最大的不同是：資料的先後順序本身就是資訊。

時間序列分析

同一個標的沿著時間觀察，例如「2330 過去 20 日動能是否延續？」

橫斷面分析

同一天比較許多標的，例如「今天哪一檔股票的估值／成長綜合排名較高？」

Panel／面板資料

同時有股票與時間兩個維度。本站的每日因子快照就是這一類。

簡單報酬rₜ = Pₜ / Pₜ₋₁ − 1
對數報酬gₜ = log(Pₜ / Pₜ₋₁)

原始價格通常有趨勢且尺度不穩定；報酬比較接近「今天相對昨天發生多少變化」，也較容易跨股票比較。但共整合等問題會刻意研究非平穩的價格水準，並非所有模型都必須先改成報酬。除權息、分割與現金股利仍需正確調整。

02 · DECOMPOSE THE QUESTION

先把市場問題拆成四層

1

水準與趨勢

價格或營收長期往哪裡移動？移動平均與指數平滑主要處理這一層。

2

季節性與週期

是否有每月、每季、農曆年或景氣循環的重複型態？月營收尤其容易有季節性。

3

短期依賴

今天的變化是否和過去幾天相關？ACF、PACF、ARIMA 嘗試描述這種關係。

4

波動與狀態切換

大波動常跟著大波動，且牛熊市場的規則可能不同。Rolling volatility、GARCH 與 regime 模型處理這一層。

03 · DATA BEFORE MODEL

模型之前，先把資料時間對齊

時間序列研究最危險的錯誤，往往不是演算法，而是把「當時還不知道的資料」放進訊號。台股資料又同時包含每日價格、每月營收、每季財報與不定期重大訊息，不能只靠日期欄位直接合併。

最低限度檢查

  • 可得時間：月營收屬於哪一個月份，不等於市場在哪一天得知它；應以公布日對齊。
  • 交易日：週末、休市與颱風假不能當成缺失交易日任意補價。
  • 公司行動：除權息、股票分割與減資可能讓價格跳動，但不代表投資人真的損失相同比例。
  • 缺值與離群：空值不等於零；異常值應先查來源，再決定 winsorize、保留或排除。
  • Universe：歷史研究必須避免只保留今天仍上市、今天看起來成功的公司。

04 · METHOD MAP

常見分析方法：它們各自回答什麼？

沒有一個方法同時適合所有問題。先決定要描述、預測平均報酬、預測波動，還是比較多個股票，再選模型。

方法主要問題適合輸入優點重要限制
Naive baseline明天和今天差不多嗎？價格、報酬、波動最難被誤解，也是所有模型應擊敗的基準不描述結構變化
SMA／EMA趨勢是否持續？價格、營收透明、容易監控落後且對視窗敏感
Rolling z-score目前是否偏離近期常態？價差、估值、成交量適合異常偵測與均值回歸假說常態水準可能突然改變
分解／Holt-Winters趨勢與季節性各占多少？月營收、需求量可解釋季節型資料市場價格季節性通常不穩定
ACF／PACF過去多少期仍有關聯？報酬、差分後序列診斷時間依賴的基本工具相關不等於可交易獲利
ARIMA／SARIMA線性自我依賴能否預測？平穩或差分後序列統計假設清楚、有區間預測難處理非線性與 regime 切換
Rolling vol／GARCH未來風險可能多大？日報酬抓到波動群聚，適合部位與風控不是方向預測器
VAR／共整合多個序列是否共同移動？指數、產業、利率、價差分析跨市場關係變數多時很容易過度擬合
Tree／Boosting多種落後特徵是否含非線性訊號？lag、rolling、因子特徵能處理交互作用切分錯誤就會嚴重洩漏未來
LSTM／Transformer長短期序列模式能否自動學習？大量且一致的序列樣本表達能力高資料需求大、難解釋，不保證勝過簡單基準
橫斷面 Rank IC高分股票之後是否相對較強？每日股票因子與未來報酬直接檢驗排序能力屬面板／因子研究，不是單一股票時間序列預測

05 · TRUSTWORTHY WORKFLOW

可信的分析流程，不從挑模型開始

  1. 寫清楚問題。預測方向、報酬、波動，還是比較股票？預測 1D、5D 還是 20D？
  2. 建立 point-in-time 資料。每筆資料必須標示市場當時何時能得知，而不只是它描述哪一期。
  3. 保留最簡單 baseline。Naive、移動平均或簡單排名若已足夠，複雜模型沒有免費加分。
  4. 按時間切分。訓練在前、驗證在後；不可隨機洗牌讓明天跑進昨天。
  5. Walk-forward。只用當時以前資料重新訓練，再向前測一段，重複模擬真實上線。
  6. 計入成本與限制。手續費、交易稅、滑價、漲跌停、流動性與可放空性都會改變結果。
  7. 上線後持續 OOS。固定訊號版本、保存 prediction，再等答案成熟；不能看到結果後改寫過去。
Historical holdout一次時間切分

用較早資料開發、較晚一段驗證；仍是已存在的歷史資料。看過結果後若持續調參，這段資料就不再是獨立 holdout。

Historical walk-forward模擬逐期上線

每一期只看當時以前資料，但研究者今天仍已擁有完整歷史；不等於真實 live 紀錄。

Live Forward OOS上線後才知道答案

訊號在日期到來時永久保存，未來成熟後才評分；本站因子 ledger 採這一層。

06 · THIS PROJECT

本站的 5D Forward OOS 怎麼走？

因子層在交易日收盤資料與官方估值、營收資料都到齊後，建立當日股票排序。這裡的 snapshot 是一次帶有交易日、記錄時間、模型版本與來源雜湊的官方資料快照；同一交易日不重複追加。為了不假設能事後用訊號日收盤成交，評估固定使用下一個市場 snapshot 作 entry、再往後第 5 個市場 snapshot 作 exit。

t₀固定訊號保存因子分數與版本
→
t₁Entry proxy下一市場 snapshot 的官方收盤；缺價即排除
→
t₁…t₆等待 5D期間不得偷看答案
→
t₆Outcome計算 Rank IC／五分位差
為什麼 5D 要等至少 6 個後續快照？

第一個後續交易日只負責提供可執行的 entry proxy，之後還要完整走過 5 個交易日才有 exit。這比直接拿訊號日收盤計算更保守。

六個價格的簡化例子

假設訊號在 t₀ 固定；t₁ 收盤為 100，經過五個完整交易期間後 t₆ 收盤為 105，研究用 5D forward return 是 105 / 100 − 1 = 5%。即使 t₀ 收盤是 90，也不拿 90 當 entry。

Entry proxy 不是保證成交價。若個股在指定 entry 或 exit snapshot 沒有有效官方價格，該股票會從該次橫斷面 outcome 排除；系統不延後期限，也不沿用舊價，並保留實際有效樣本數。若只在 t₂–t₅ 缺價、但 t₁ 與 t₆ 有效，端點報酬仍會納入，因此仍可能帶來停牌／流動性選擇偏誤。真實策略還要指定下一日開盤、VWAP 或限價規則，並處理漲跌停、停牌、滑價與成交量限制。

07 · READ THE RESULT

看到結果時，先問這些問題

Rank IC

因子排名與未來報酬排名的 Spearman correlation。正值表示高分股票傾向排在較高未來報酬位置；單日正值沒有決定性。它只反映相對排序，不代表絕對正報酬、報酬幅度或扣除成本後可獲利。實作時還要固定股票池、缺值規則與並列名次算法。

Top − Bottom

最高與最低五分位的平均未來報酬差。它適合檢驗排序，但 Bottom 空方未必能實際放空。

Turnover

排名組合更換的幅度。毛報酬漂亮但每天換股，可能全部被成本吃掉。

Max Drawdown

從資產曲線高點到後續低點的最大跌幅。它只代表特定期間、取樣頻率與資產路徑的已實現結果，不是未來損失上限，也未說明回復時間與尾端風險。重疊持倉只有在資金分配、同期曝險與再平衡規則明確時，才形成可解讀的組合曲線；本站另列非重疊持有期來降低標籤相依性，但它受抽樣起點影響，不是較保守的損失界線或完整策略曲線。

Prediction interval

合理模型應提供不確定範圍，而非只有單一精確數字。區間寬度同時受信心水準、預測期限、資產波動與模型設定影響；它不是保證範圍。模型假設錯誤、厚尾或 regime 改變時，實際涵蓋率可能遠低於標示值，必須用 OOS 持續校準。

Regime stability

多頭、空頭、高波動與盤整期是否都可接受？只靠單一年份，通常不是可靠 edge。

三檔股票的 Rank IC 直覺

若因子分數排序為 A ＞ B ＞ C，而未來報酬分別為 +6%、+1%、−2%，兩邊排名完全一致，Rank IC 為 +1；若未來報酬順序完全相反則為 −1。真實研究會有數百檔、缺值與並列排名，因此應跨多個日期觀察平均值與分布，而非只看單日。

08 · FAILURE MODES

八個最常讓回測看起來太好的陷阱

Lookahead bias用了當時尚未公布的財報、營收或未來價格。
Survivorship bias只用今天還存在的股票回測過去。
Random split把時間資料洗牌，讓未來型態進入訓練集。
Overlapping labels大量 5D 樣本共享同一批報酬，卻被當成獨立證據。
Multiple testing試了數百個參數，只報告最好的一個。
Ignoring costs忽略標準手續費率參考值 0.1425%；依證交所規則，證券商可自行訂定費率、折讓與最低費用，另有賣出稅、滑價與流動性成本。
Non-stationarity假設過去關係永遠不變，沒有監控 regime 或模型漂移。
Metric shopping只挑勝率或總報酬，避談 drawdown、turnover 與基準。

09 · CHOOSE A METHOD

一分鐘方法選擇表

想知道趨勢？先看報酬圖、SMA／EMA、rolling slope
想知道營收季節性？月資料分解、YoY、Holt-Winters／SARIMA
想預測風險？Rolling volatility，再考慮 GARCH
想比較股票高低分？橫斷面 percentile、Rank IC、五分位差
想加入多種資料？先做 lag／rolling 特徵，再用 boosting；必須 walk-forward
樣本不多？停在簡單模型；不要用深度學習補足資料不足

THE PRACTICAL RULE

先問「如何證明它錯」，再問「能賺多少」。

可靠的投資研究不是找到一條永遠上漲的曲線，而是讓資料來源、訊號時間、驗證方式與失敗條件都能被重現。

10 · GLOSSARY

名詞快速查找

平穩 Stationarity
序列的平均、變異與相關結構大致不隨時間漂移；許多統計模型依賴這項假設。
差分 Differencing
用本期減前期，移除部分趨勢；報酬可視為價格變化的相對版本。
Lag
過去第幾期的值，例如 lag 1 是上一期。
ACF／PACF
描述序列與不同 lag 的相關，以及控制較短 lag 後的額外相關。
Regime
市場行為相似的一段狀態，例如多頭、空頭或高波動期。
Walk-forward
按時間逐步向前，每次只用當時以前資料訓練與驗證。
Universe
某日期允許進入研究或投資的股票集合，必須用 point-in-time 規則定義。
Winsorize
把極端值壓到指定分位邊界，而不是直接刪除；必須事先定義規則。
Spearman correlation
對排名計算的相關係數，較關心順序而非原始數值距離。
Snapshot
某一時點已知資料與版本的不可變紀錄，用來證明當時模型實際看見什麼。
